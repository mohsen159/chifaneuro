# About Chifanoure

**Chifanoure** is a memo/web application developed as my final year project for the L3 Informatique (Bachelor of Computer Science) program.

## Project Overview

This project is a functional memo application designed to demonstrate core web development skills. It serves as a practical implementation of the concepts learned throughout my degree.

## Note

This is a academic project, and as such, you may find some inconsistencies or typos in the code and documentation as it was a learning process.
